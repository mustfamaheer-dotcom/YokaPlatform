## نظرة عامة على النظام

### الوصف الأساسي

**اسم النظام:** منصة التجارة الإلكترونية المتكاملة (Integrated E-Commerce Platform)

**النوع:** منصة إلكترونية متعددة الفروع للبيع الإلكتروني

**الهدف الرئيسي:** توفير منصة متجر إلكترونية متقدمة متصلة بنظام إدارة المبيعات والمخازن الداخلي لتوسيع قنوات البيع وزيادة الوصول للعملاء.

### الفرق عن البيع التقليدي

| المعيار | البيع التقليدي (POS) | البيع الإلكتروني (E-Commerce) |
|--------|-------------------|---------------------------|
| **ساعات العمل** | محدودة بساعات الفرع | 24/7 |
| **الوصول الجغرافي** | محدود بموقع الفرع | عالمي |
| **التكاليف** | إيجار، موظفين | استضافة، تسويق |
| **عدد الزوار** | عدد محدود يومياً | عدد غير محدود |
| **الدفع** | حاضر (كاش، بطاقة) | إلكتروني فقط |
| **الشحن** | توصيل يدوي | خدمات شحن متعددة |

### المميزات الرئيسية

- **واجهة مستخدم متقدمة:** تصميم حديث وسهل الاستخدام
- **إدارة منتجات ديناميكية:** تحديث فوري للأسعار والمخزون
- **نظام تسويق قوي:** إعلانات، عروض، برامج ولاء
- **تكامل فوري مع المخزن:** تحديث أرصدة فورية
- **معالجة طلبات متقدمة:** تتبع، إدارة عوائد
- **تحليلات متقدمة:** بيانات دقيقة عن السلوك
- **دعم عملاء متعدد القنوات:** دردشة، بريد، هاتف

### الفوائد المتوقعة

1. **زيادة الإيرادات:** قناة بيع جديدة 24/7
2. **توسيع السوق:** الوصول لعملاء جدد خارج المدينة
3. **تقليل التكاليف:** بدون موظفين إضافيين كثيرين
4. **جمع البيانات:** فهم أعمق لسلوك العملاء
5. **الميزة التنافسية:** مواكبة التطور التكنولوجي

## الهندسة المعمارية

### المعمارية العامة للنظام

```
┌─────────────────────────────────────────────────────────┐
│                   موقع التجارة الإلكترونية                 │
│              (Frontend - Public Facing)                  │
├─────────────────────────────────────────────────────────┤
│  صفحة البحث │ عرض المنتجات │ سلة التسوق │ الدفع │ الحساب │
└─────────────────────┬─────────────────────────────────┘
                      │ APIs
┌─────────────────────▼─────────────────────────────────┐
│            طبقة التطبيق (Backend Services)             │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │ إدارة    │ │ معالجة  │ │ إدارة    │ │ نظام     │ │
│  │ المنتجات │ │ الطلبات │ │ العملاء  │ │ الشحن    │ │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘ │
└─────────────────────┬─────────────────────────────────┘
                      │
        ┌─────────────┼─────────────┐
        │             │             │
┌───────▼──────┐ ┌───▼──────────┐ ┌──▼──────────────┐
│ قاعدة البيانات│ │نظام المخزون  │ │نظام الدفع      │
│   E-Commerce │ │  والمبيعات   │ │والشحن          │
└───────┬──────┘ └───┬──────────┘ └──┬──────────────┘
        │             │               │
        └─────────────┴───────────────┘
        (المزامنة الفورية - Real-time Sync)
```

### طبقات النظام

#### 1. طبقة العرض (Presentation Layer)

**الويب:**
- ReactJS / Vue.js / Angular
- Bootstrap / Tailwind CSS
- Responsive Design

**الأجهزة المحمولة:**
- React Native / Flutter
- PWA (Progressive Web App)

#### 2. طبقة الواجهات البرمجية (API Layer)

- REST APIs أو GraphQL
- توثيق شاملة للـ APIs
- معايير الأمان (OAuth 2.0)

#### 3. طبقة الخدمات (Services Layer)

- **خدمة المنتجات:** البحث، التصنيفات، التقييمات
- **خدمة الطلبات:** الإنشاء، التحديث، الإلغاء
- **خدمة العملاء:** التسجيل، الملفات الشخصية
- **خدمة الدفع:** معالجة المدفوعات الآمنة
- **خدمة الشحن:** حساب الرسوم، التتبع

#### 4. طبقة البيانات (Data Layer)

- قاعدة بيانات E-Commerce
- قاعدة بيانات نظام المبيعات (متزامنة)
- Caching Layer (Redis)

```
    └─────────────────┘
```

## أدوار المستخدمين والصلاحيات

### 1. العميل (Customer)

#### المعلومات الأساسية
- أقل مستويات الصلاحيات
- يتفاعل مع الواجهة الأمامية فقط
- ليس له وصول لأي بيانات إدارية

#### الصلاحيات

| الوحدة | الصلاحية |
|------|--------|
| **المنتجات** | البحث، التصفية، عرض التفاصيل، التقييم |
| **السلة** | إضافة، حذف، تعديل الكمية |
| **الدفع** | اختيار طريقة دفع، إدخال بيانات |
| **الطلبات** | عرض تاريخ، التتبع، الإلغاء |
| **الحساب** | تحديث البيانات الشخصية، كلمة المرور |
| **الاتصال** | إرسال رسائل دعم، شكاوى |

#### الشاشات المتاحة

1. **الصفحة الرئيسية**
   - عرض المنتجات الجديدة
   - العروض الخاصة
   - الفئات الرئيسية
   - شريط البحث

2. **صفحة تصفح المنتجات**
   - قائمة المنتجات
   - الفلاتر والتصفية
   - الترتيب (السعر، التقييم، الجديد)
   - عرض الشبكة أو القائمة

3. **صفحة تفاصيل المنتج**
   - الصور المتعددة
   - الوصف الكامل
   - الأسعار والعروض
   - التقييمات والمراجعات
   - الخيارات (اللون، الحجم، الكمية)
   - الأسئلة والإجابات

4. **سلة التسوق**
   - قائمة المنتجات المضافة
   - الكمية والسعر
   - حساب الإجمالي
   - رموز الخصم
   - خيارات الشحن

5. **صفحة الدفع**
   - ملخص الطلب
   - عنوان الشحن
   - طريقة الدفع
   - مراجعة نهائية
   - تأكيد الطلب

6. **حسابي (My Account)**
   - البيانات الشخصية
   - عناويني
   - طلباتي السابقة
   - المفضلة
   - الكوبونات الخاصة بي

7. **صفحة الطلب**
   - تفاصيل الطلب
   - حالة الشحن
   - معلومات التتبع
   - خيارات الإرجاع

8. **دعم العملاء**
   - نموذج الشكاوى
   - الدردشة المباشرة
   - قائمة الأسئلة الشائعة
   - الاتصال بنا

### 2. إدارة المحتوى (Content Manager)

#### المعلومات الأساسية
- مسؤول عن محتوى الموقع
- تحديث المنتجات والأسعار والصور
- إدارة العروض والتسويق

#### الصلاحيات

| الوحدة | الصلاحية |
|------|--------|
| **المنتجات** | إضافة، تعديل، حذف، تحديث الصور والأسعار |
| **التصنيفات** | إضافة، تعديل، ترتيب |
| **العروض** | إنشاء، تعديل، إلغاء |
| **الصفحات الثابتة** | عن الشركة، الشروط، السياسة |
| **الإعلانات** | إضافة، إدارة |
| **المراجعات** | مراجعة، قبول، رفض، حذف |

#### الشاشات المتاحة

1. **إدارة المنتجات**
   - إضافة منتج جديد
   - تعديل تفاصيل المنتج
   - رفع الصور
   - تحديث الأسعار
   - إدارة المخزون (عرض فقط)
   - نسخ منتج موجود

2. **إدارة التصنيفات**
   - إضافة تصنيف جديد
   - تعديل التصنيفات
   - ترتيب التصنيفات
   - إدارة العلامات (Tags)

3. **إدارة العروض والتخفيضات**
   - إنشاء عرض جديد
   - تحديد المنتجات المشمولة
   - نسبة الخصم والمدة
   - كود الكوبون

4. **الصفحات الثابتة**
   - تعديل صفحة "عن الشركة"
   - تحديث شروط الخدمة
   - سياسة الخصوصية
   - سياسة الإرجاع

5. **إدارة المراجعات**
   - عرض التقييمات والتعليقات
   - قبول أو رفض التعليقات
   - حذف التعليقات غير المناسبة
   - الرد على المراجعات

## وحدات النظام الرئيسية

### 1. وحدة المنتجات (Product Management)

#### المميزات الرئيسية

- **إدارة شاملة للمنتجات:** إضافة، تعديل، حذف
- **صور متعددة:** معرض صور، صورة رئيسية
- **أسعار متغيرة:** سعر عادي، سعر مخفض، أسعار مختلفة
- **المتغيرات:** ألوان، أحجام، أنماط
- **التصنيفات والعلامات:** تنظيم فعال
- **الوصف الغني:** HTML، نصوص، جداول

#### البيانات المسجلة

```
نموذج المنتج:
├── معرف المنتج (ID)
├── SKU (رمز الأرتفاع)
├── الاسم
├── الوصف
├── الفئة الرئيسية
├── الفئات الفرعية
├── العلامات (Tags)
├── الصور
│   ├── صورة رئيسية
│   ├── صور إضافية
│   └── صور مكبرة
├── الأسعار
│   ├── السعر الأساسي
│   ├── السعر المخفض
│   ├── سعر التكلفة
│   └── الضريبة
├── المخزون
│   ├── الكمية المتاحة
│   ├── المحجوزة
│   └── الكمية المبيعة
├── الوزن والأبعاد
├── المتغيرات
│   ├── الألوان
│   ├── الأحجام
│   └── المواصفات الأخرى
├── التقييمات والمراجعات
├── الكلمات المفتاحية (SEO)
├── URL صديقة (Slug)
└── حالة النشر (منشور/مسودة)
```

### 2. وحدة السلة والدفع (Cart & Checkout)

#### المميزات الرئيسية

- **سلة ذكية:** حفظ تلقائي، متزامن
- **الكوبونات والخصومات:** كود، نسبة، حد أدنى
- **حساب الضرائب:** حسب المنطقة
- **خيارات الشحن:** شركات متعددة، حسابات فورية
- **الدفع الآمن:** تشفير SSL، معايير PCI

#### خطوات عملية الشراء

```
1. إضافة المنتج للسلة
   ↓
2. مراجعة السلة
   ↓
3. إدخال عنوان الشحن
   ↓
4. اختيار طريقة الشحن
   ↓
5. إدخال بيانات الدفع
   ↓
6. مراجعة الطلب
   ↓
7. تأكيد الطلب
   ↓
8. معالجة الدفع
   ↓
9. تأكيد الطلب برقم فاتورة
   ↓
10. إرسال رسالة تأكيد بريد إلكتروني
```

### 3. وحدة إدارة الطلبات (Order Management)

#### المميزات الرئيسية

- **تتبع الطلبات:** من الإنشاء للتسليم
- **حالات الطلب:** قيد المعالجة، مشحون، مسلم
- **معالجة المرتجعات:** إرجاع، استبدال، استرجاع أموال
- **إدارة الفواتير:** إصدار، طباعة، إرسال

#### حالات الطلب

```
طلب جديد (New)
   ↓
قيد المعالجة (Processing) - يتم جمع المنتجات من المخزن
   ↓
جاهز للشحن (Ready to Ship) - تم التحقق من المنتجات
   ↓
مشحون (Shipped) - تم تسليم للشركة اللوجستية
   ↓
قيد التسليم (In Transit) - في الطريق للعميل
   ↓
مسلم (Delivered) - وصل العميل
   ↓
مكتمل (Completed) - انتهت العملية
   
   أو
   
ملغى (Cancelled) - ألغى العميل
```

### 4. وحدة إدارة العملاء (Customer Management)

#### المميزات الرئيسية

- **ملف العميل الشامل:** بيانات شخصية، عناوين، رغبات
- **سجل التاريخ:** جميع الطلبات والتفاعلات
- **المفضلة والقوائم:** منتجات مفضلة
- **برنامج الولاء:** نقاط، مستويات، مكافآت

```sql
    first_name VARCHAR(100) NOT NULL,
    last_name VARCHAR(100) NOT NULL,
```

```sql
    usage_limit INT,
    
    -- التتبع
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### 3. معالجة الطلبات

```

   ├── إنشاء طلب في Legacy System
   ├── حجز المخزون
   ├── تسجيل العملية
   └── تأكيد للعميل

   ├── تحديث حالة الطلب

   ├── تحديث حالة الشحن
   ├── تسجيل في المبيعات
   ├── تحديث العميل
   └── إغلاق الطلب
```

#### 4. تحديث الأسعار والعروض

```
تدفق تحديث الأسعار:

Admin يحدّث السعر في Legacy
   ↓
إرسال إشعار للـ E-Commerce API
   ↓
تحديث السعر في قاعدة البيانات
```

```
كل ساعة:
- مصالحة شاملة للبيانات
- التحقق من الاتساق
```

### التعامل مع تضارب المخزون

#### السيناريوهات المحتملة

1. **بيع من نقطة بيع والويب في نفس الوقت:**
   ```
   المخزون الأصلي: 10 وحدات
   
   سيناريو أ: بيع من الويب 3 وحدات، وقت 12:00
   سيناريو ب: بيع من الفرع 5 وحدات، وقت 12:00
   
   الحل: نظام قفل (Locking) يمنع البيع المزدوج
   النتيجة: المخزون = 2 وحدة (10 - 3 - 5)
   ```

2. **تحديث السعر أثناء الشراء:**
   ```
   العميل يختار المنتج بسعر 100 ريال
   الأدمن يغير السعر إلى 90 ريال
   
   الحل: حفظ السعر وقت الإضافة للسلة
   ```

3. **خروج المنتج من المخزون:**
   ```
   المنتج في السلة، لكن انتهى من المخزن
   
   الحل: إخطار العميل قبل الدفع
   خيار: استبدال أو إلغاء
   ```

### نظام الحجز

```
حالات المخزون:

إجمالي = متاح + محجوز + مباع

مثال:
المنتج A:
├── الإجمالي: 100 وحدة
├── المتاح: 85 وحدة (يمكن بيعه الآن)
├── المحجوز: 10 وحدات (في سلات غير مدفوعة)
└── المباع: 5 وحدات (في طلبات قيد الشحن)

عملية الحجز:
1. عند إضافة للسلة: تحجز وحدة واحدة (15 دقيقة)
2. عند الدفع: تحويل الحجز إلى مباع
3. عند انتهاء المدة: إلغاء الحجز، استرجاع للمتاح
4. عند التسليم: نقل من المباع إلى مبيع نهائي
```

```
رسم الشحن = (أساس ثابت) + (سعر لكل كجم × الوزن)
```
