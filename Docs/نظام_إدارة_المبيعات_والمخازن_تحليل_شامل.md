## نظرة عامة على النظام

### الوصف الأساسي

**اسم النظام:** نظام إدارة المبيعات والمخازن المتعددة (Multi-Branch Sales & Inventory Management System)

**النوع:** منصة سحابية/شبكية متكاملة

**الهدف الرئيسي:** إدارة شاملة لعمليات المبيعات والمخزون والعمليات الحسابية لشركة تمتلك مخزناً رئيسياً وعدة فروع بيع تجزئة.

### الخصائص الرئيسية

- **عدم تمركز العمليات اليومية:** كل فرع لديها استقلالية كاملة في إدارة عملياتها اليومية
- **رقابة مركزية صارمة:** الإدارة العليا (الأدمن) لها رقابة كاملة على جميع العمليات
- **التكامل الكامل:** ربط سلس بين المشتريات والتخزين والمبيعات والمالية
- **مرونة عالية:** دعم طرق دفع متعددة وإمكانية دمج أكثر من طريقة في فاتورة واحدة
- **معالجة البيانات الفورية:** تحديث فوري للأرصدة والمستحقات المالية

### المشاكل التي يحلها النظام

1. عدم الرؤية الكاملة للمخزون عبر الفروع المختلفة
2. صعوبة تتبع المستحقات المالية للموردين والعملاء
3. عدم القدرة على سحب تقارير فورية ودقيقة
4. احتمالية التلاعب والاختلاسات في الأموال والمخزون
5. صعوبة إدارة النقدية والتحويلات بين الفروع والمقر الرئيسي

## الهندسة المعمارية

### الهيكل المعماري العام

```
┌─────────────────────────────────────────────────────────────┐
│                     المقر الرئيسي - الأدمن                    │
│  (لوحة التحكم + قاعدة البيانات المركزية + التقارير المتقدمة)      │
└────────────┬────────────────────────────────┬────────────────┘
             │                                │
     ┌───────▼────────┐           ┌──────────▼──────────┐
     │   المخزن       │           │    الموردين         │
     │   الرئيسي      │           │  (المشتريات)         │
     └───────┬────────┘           └─────────────────────┘
             │
      ┌──────┴──────┬──────────┬─────────────┐
      │             │          │             │
  ┌───▼──┐      ┌───▼──┐   ┌───▼──┐     ┌───▼──┐
  │ فرع  │      │ فرع  │   │ فرع  │  ...│ فرع  │
  │ (1)  │      │ (2)  │   │ (3)  │     │ (N)  │
  └───┬──┘      └───┬──┘   └───┬──┘     └───┬──┘
      │             │          │             │
  ┌───▼──────────────▼──────────▼────────────▼──┐
  │          وحدة نقاط البيع (POS)              │
  │    (المبيعات + المصروفات + يومية الفرع)      │
  └────────────────────────────────────────────┘
```

### مستويات الطبقات (Layers)

#### 1. طبقة العرض (Presentation Layer)
- واجهات مستخدم منفصلة لكل دور (أدمن، مشرف، بائع)
- شاشات متجاوبة تعمل على الويب والأجهزة المحمولة
- لوحات معلومات (Dashboards) بتصور البيانات

#### 2. طبقة التطبيق (Application Layer)
- منطق الأعمال الأساسي
- معالجة الصلاحيات والتحكم بالوصول
- معالجة دورات العمل والعمليات

#### 3. طبقة البيانات (Data Layer)
- قاعدة البيانات المركزية
- نقل البيانات بين الفروع والمقر
- المزامنة في الوقت الفعلي

#### 4. طبقة التكامل (Integration Layer)
- ربط مع أنظمة الدفع الإلكترونية
- التكامل مع البنوك
- التكامل مع أنظمة ERP الأخرى

### معمارية قاعدة البيانات

**نموذج البيانات المركزي:**
- قاعدة بيانات رئيسية واحدة في المقر الرئيسي
- نسخ محلية مع مزامنة فورية في كل فرع (عند الاتصال)
- نسخة احتياطية من البيانات يومياً

**مستويات الوصول:**
- الأدمن: وصول كامل لجميع البيانات
- المشرف: وصول مقيد لبيانات فرعه فقط
- البائع: وصول محدود جداً (فقط لإصدار الفواتير)

## أدوار المستخدمين والصلاحيات

### 1. الأدمن الرئيسي (Main Administrator)

#### الصفات والمسؤوليات
- المسؤول الأعلى للنظام بأكمله
- صاحب السيطرة الكاملة على جميع العمليات
- المسؤول عن الإشراف المركزي والرقابة المالية

#### الصلاحيات

| الوحدة | الصلاحية |
|------|--------|
| **إدارة الفروع** | إضافة/تعديل/حذف الفروع، إدارة الخزائن |
| **إدارة الموردين** | إضافة موردين، إدارة أرصدتهم، السداد والتحصيل |
| **المشتريات** | إدخال فواتير الشراء، تحديد المواصفات، طباعة الباركود |
| **التوزيع** | نقل المنتجات بين المخزن الفروع والفروع ببعضها |
| **التقارير** | الوصول لجميع التقارير المتقدمة والتحليلات |
| **الجرد** | إجراء جرد شامل للمخزون، تسوية الكميات |
| **اليوميات** | عرض اليوميات الإدارية الشاملة |
| **الموارد البشرية** | إضافة وإدارة البائعين والموظفين |
| **المالية** | تتبع النقدية، الخزائن، المصروفات |

#### الشاشات المتاحة للأدمن

1. **لوحة التحكم والتقارير**
   - مؤشرات الأداء الرئيسية (KPIs)
   - إيرادات الأيام الماضية
   - أكثر المنتجات مبيعاً
   - توزيع المبيعات حسب الفروع

2. **صفحة الفروع والخزائن**
   - عرض قائمة الفروع
   - إضافة فرع جديد (الاسم، الرقم، العنوان)
   - إدارة خزائن الفروع
   - الخزنة الرئيسية

3. **صفحة الموردين**
   - إضافة مورد جديد (الاسم، رقم المورد، العنوان، الرصيد الافتتاحي)
   - عرض قائمة الموردين برصيدهم الحالي
   - سداد مستحقات المورد مع تحديد طريقة الدفع
   - تحصيل من المورد
   - كشف حساب تفصيلي للمورد

4. **صفحة المشتريات (الواردات)**
   - المخزن المستقبل يحدد تلقائياً (المخزن الرئيسي)
   - إدخال الأصناف بتفاصيلها:
     * رقم الصنف
     * الاسم
     * العلامة التجارية
     * التصنيف (الفئة)
     * المادة
     * اللون
     * الحجم
     * سعر التكلفة
     * سعر البيع
     * الكمية
     * الوصف
     * الصور
   - تحديد المورد
   - اختيار طريقة الدفع (كاش/آجل)
   - إضافة خصومات
   - طباعة باركود لكل منتج
   - تحديث الأصناف الموجودة مع تعديل الأسعار والكميات

5. **صفحة إذن الصرف (توزيع المنتجات)**
   - نقل من المخزن الرئيسي إلى الفروع
   - نقل بين الفروع
   - تحديد المنتج والكمية
   - تحديث الأرصدة تلقائياً
   - طباعة PDF

6. **صفحة المجموعات والأصناف**
   - إدارة التصنيفات الرئيسية
   - إدارة الأصناف وربطها بالمجموعات
   - تحديد الوحدة الكبرى
   - تحديد أسعار البيع المتعددة

7. **صفحة يومية الفروع**
   - عرض تفصيلي لكل فاتورة بيع
   - تصفية حسب الفرع والتاريخ
   - عرض الإجمالي الوارد والمنصرف والصافي
   - تفصيل طرق الدفع (كاش، تحويلات، فيزا)

8. **صفحة الجرد المجمع**
   - عرض كامل المخزون المتوفر
   - طباعة قائمة الجرد
   - إدخال الكميات الفعلية
   - تحديد العجز والزيادة

9. **صفحة سند التسوية**
   - مقارنة الرصيد المسجل مع الفعلي
   - عرض الفروق والعجز
   - طباعة سند التسوية

10. **صفحة اليوميات الإدارية**
    - **قسم المصروفات:**
      * الصرف من البائعين
      * فواتير الخدمات
      * المصاريف الأخرى
    - **قسم العمليات الإدارية:**
      * نقل من مخزن لآخر
      * سداد للموردين
      * إضافة مشتريات
      * صافي الوارد بعد خصم المصاريف
    - **قسم الأرباح:**
      * الإيرادات الإجمالية
      * إجمالي الربح
      * صافي الربح

11. **صفحة مندوبي البيع (البائعين)**
    - إضافة بائع جديد
    - البيانات: الاسم، الهاتف، الرقم القومي، الفرع، المرتب
    - عرض قائمة البائعين

### 2. المشرف (Supervisor / Branch Manager)

#### الصفات والمسؤوليات
- مدير الفرع
- مسؤول عن جميع العمليات داخل الفرع فقط
- أدمن مصغر في نطاق فرعه
- مسؤول عن تسليم النقدية اليومي

#### الصلاحيات

| الوحدة | الصلاحية |
|------|--------|
| **المبيعات** | الوصول الكامل لشاشات المبيعات |
| **المصروفات** | تسجيل جميع أنواع المصروفات |
| **الخزينة** | تحويل النقدية للخزنة الرئيسية |
| **الجرد** | إجراء جرد الفرع وتسوية الكميات |
| **يومية الفرع** | عرض جميع حركات الفرع |
| **البائعين** | إدارة البائعين في الفرع |

#### الشاشات المتاحة للمشرف

1. **جميع صفحات المبيعات والمصروفات الخاصة بفرعه**

2. **صفحة حركات الخزينة**
   - عرض رصيد خزنة الفرع الحالي
   - إدخال عملية تحويل نقدية
   - تحديد المبلغ المراد تحويله
   - تسليم النقدية إلى الخزنة الرئيسية
   - تسجيل تاريخ ووقت التحويل تلقائياً
   - طباعة إيصال التحويل

3. **صفحة جرد الفرع**
   - إجراء جرد شامل لمخزون الفرع
   - مقارنة الرصيد المسجل مع الفعلي
   - تحديد العجز والزيادة
   - إصدار سند التسوية

4. **لوحة معلومات الفرع**
   - مؤشرات الأداء الخاصة بالفرع
   - إجمالي المبيعات اليومية
   - أداء البائعين
   - حركات المخزون

---

### 3. البائع (Salesperson / Cashier)

#### الصفات والمسؤوليات
- واجهة البيع الرئيسية مع العملاء
- تسجيل العمليات البيعية
- استقبال الأموال
- تسجيل المصروفات البسيطة

#### الصلاحيات

| الوحدة | الصلاحية |
|------|--------|
| **المبيعات** | إصدار الفواتير فقط |
| **المصروفات** | تسجيل المصروفات البسيطة |
| **يومية البائع** | عرض سجل حركاته الشخصية |

#### الشاشات المتاحة للبائع

1. **شاشة تسجيل الدخول**
   - اسم المستخدم (بائع/مشرف)
   - كلمة السر
   - اختيار الفرع

2. **صفحة فاتورة جديدة (نقاط البيع - POS)**
   - **بيانات العميل:**
     * الاسم
     * رقم العميل (اختياري)
     * العنوان
   - **تفاصيل الأصناف:**
     * البحث عن الصنف (F1)
     * إضافة صنف جديد (F12)
     * كود المنتج
     * الكمية
     * السعر (يُحسب تلقائياً)
     * الخصم (إن وجد)
     * السعر النهائي
   - **طرق الدفع المتعددة:**
     * كاش
     * فيزا/بطاقات ائتمان
     * تحويلات بنكية
     * محافظ إلكترونية
   - **العمليات:**
     * حفظ الفاتورة
     * طباعة الفاتورة
     * إلغاء الفاتورة

3. **صفحة المصروفات**
   - اختيار نوع الصرف من قائمة منسدلة:
     * صرف نقدية (سحب من البائع)
     * فواتير الخدمات (مياه، كهرباء، إيجار)
     * مصاريف أخرى (منظفات، شحن)
   - إدخال المبلغ
   - إضافة ملاحظات
   - تسجيل المصروف

4. **صفحة يومية البائع (Daily Shift)**
   - عرض ملخص الوردية
   - إجمالي المبيعات
   - عدد الفواتير
   - توزيع طرق الدفع
   - إجمالي المصروفات

## دورات العمل والتدفقات

### دورة 1: المشتريات والموردين

```
البداية
   ↓
تسجيل بيانات المورد
   ↓
إنشاء فاتورة شراء
   ↓
إدخال الأصناف والكميات والأسعار
   ↓
تحديد طريقة الدفع (كاش/آجل)
   ↓
تأكيد الفاتورة
   ↓
دخول البضاعة تلقائياً للمخزن الرئيسي
   ↓
تسجيل المستحقات المالية للمورد
   ↓
إصدار باركود لكل منتج
   ↓
النهاية (البضاعة جاهزة للتوزيع)
```

#### الخطوات التفصيلية

1. **تسجيل المورد الجديد:**
   - اسم المورد
   - رقم تعريف المورد
   - العنوان
   - طرق التواصل
   - الرصيد الافتتاحي (إن وجد)

2. **إنشاء فاتورة الشراء:**
   - تحديد المورد
   - إدخال تاريخ الفاتورة (يسجل تلقائياً)
   - البحث عن منتج موجود أو إضافة منتج جديد
   - البيانات المطلوبة لكل منتج:
     * كود الصنف (يولد تلقائياً)
     * الاسم
     * العلامة التجارية
     * التصنيف
     * المادة
     * اللون
     * الحجم
     * سعر التكلفة (Cost Price)
     * سعر البيع (Selling Price)
     * الكمية المشتراة
     * الوصف
     * الصور (إن وجدت)

3. **إضافة الخصومات (إن وجدت):**
   - خصم على الكمية
   - خصم على الفاتورة

4. **اختيار طريقة الدفع:**
   - كاش (الدفع الفوري)
   - آجل (تأجيل السداد)

5. **حفظ الفاتورة:**
   - تحديث رصيد المخزن الرئيسي
   - تسجيل المستحقات المالية
   - طباعة الفاتورة
   - طباعة الباركود

#### النتائج
- دخول البضاعة للمخزن الرئيسي
- تسجيل ديون المورد
- إنشاء باركود للمنتجات

---

### دورة 2: التوزيع (إذن الصرف)

```
البضاعة في المخزن الرئيسي
   ↓
إنشاء إذن صرف
   ↓
تحديد المصدر (المخزن الرئيسي أو فرع)
   ↓
تحديد المقصد (فرع أو مخزن)
   ↓
إدخال الأصناف والكميات
   ↓
تأكيد الإذن
   ↓
تحديث أرصدة المصدر (تخفيض)
   ↓
تحديث أرصدة المقصد (زيادة)
   ↓
طباعة PDF للإذن
   ↓
النهاية
```

#### الخطوات التفصيلية

1. **إنشاء إذن صرف جديد:**
   - تحديد المخزن/الفرع المصدر
   - تحديد المخزن/الفرع المقصد
   - تاريخ الإذن (يسجل تلقائياً)

2. **إضافة الأصناف:**
   - البحث عن الصنف
   - تحديد الكمية المراد نقلها
   - التحقق من توفر الكمية

3. **تأكيد الإذن:**
   - عرض ملخص الأصناف والكميات
   - التأكيد النهائي

4. **التحديثات التلقائية:**
   - خصم من المخزن/الفرع المصدر
   - إضافة للمخزن/الفرع المقصد
   - تسجيل في يومية العمليات الإدارية

5. **الطباعة:**
   - طباعة إذن الصرف
   - إمكانية حفظ PDF

#### الأنواع المختلفة

- نقل من المخزن الرئيسي إلى فرع
- نقل بين الفروع
- نقل من فرع إلى المخزن الرئيسي (إرجاع)

---

### دورة 3: المبيعات (نقاط البيع - POS)

```
فتح الوردية
   ↓
استقبال العميل
   ↓
إنشاء فاتورة جديدة
   ↓
إدخال بيانات العميل
   ↓
البحث عن المنتجات (F1)
   ↓
إضافة الأصناف والكميات
   ↓
تحديد الخصومات (إن وجدت)
   ↓
اختيار طريقة الدفع
   ↓
معالجة الدفع
   ↓
طباعة الفاتورة
   ↓
خصم من رصيد الفرع
   ↓
إضافة للنقدية
   ↓
تسجيل في يومية الفرع
   ↓
النهاية
```

#### الخطوات التفصيلية

1. **فتح الوردية:**
   - تسجيل دخول البائع
   - تحديد الفرع
   - فتح رصيد الخزينة

2. **استقبال العميل:**
   - تحديد نوع العميل (عام/معروف)
   - إدخال بيانات العميل (الاسم، الرقم، العنوان)

3. **إنشاء الفاتورة:**
   - رقم فاتورة يولد تلقائياً
   - التاريخ والوقت يسجلان تلقائياً
   - اسم البائع يسجل تلقائياً

4. **البحث عن المنتجات:**
   - استخدام F1 للبحث
   - يمكن البحث بـ:
     * كود الصنف
     * اسم المنتج
     * العلامة التجارية

5. **إضافة الأصناف:**
   - اختيار المنتج
   - إدخال الكمية
   - يتم حساب السعر تلقائياً
   - إمكانية تطبيق خصم على السطر

6. **إدارة الفاتورة:**
   - إمكانية تعديل الكميات
   - إمكانية حذف أصناف
   - عرض الإجمالي المرحلي

7. **اختيار طريقة الدفع (Multi-Payment):**
   - دفع بالكامل بطريقة واحدة أو
   - دفع بطرق متعددة:
     * كاش + فيزا
     * كاش + تحويل
     * فيزا + تحويل + محفظة إلكترونية
   - حساب الكسور العشرية تلقائياً

8. **معالجة الدفع:**
   - التحقق من رصيد الحساب (إن كان بيع بالآجل)
   - معالجة بيانات البطاقة (آمناً)
   - تسجيل رقم التحويل (إن كان تحويلاً)

9. **إصدار الفاتورة:**
   - حفظ الفاتورة
   - طباعة النسخة المطبوعة
   - عرض رسالة التأكيد

10. **التحديثات التلقائية:**
    - خصم الكمية من رصيد الفرع
    - إضافة المبلغ لخزنة الفرع
    - تسجيل في يومية الفرع

11. **تسجيل إضافي:**
    - تسجيل في سجل البائع
    - تحديث إحصائيات الفرع

### دورة 4: الخزينة والمالية

```
تجميع الأموال من المبيعات طوال اليوم
   ↓
خزينة الفرع (مؤقتة)
   ↓
نهاية الوردية أو نهاية اليوم
   ↓
عداد الخزينة من قبل المشرف
   ↓
إنشاء عملية تحويل نقدية
   ↓
نقل النقدية من خزنة الفرع للخزنة الرئيسية
   ↓
تصفير عهدة الفرع
   ↓
تسجيل في اليوميات الإدارية
   ↓
اكتمال دورة اليوم
```

#### الخطوات التفصيلية

1. **تجميع الأموال:**
   - كل فاتورة تضيف مبلغها لخزينة الفرع
   - البائع لا يدير النقد مباشرة

2. **الفحص والعداد:**
   - المشرف يفحص خزينة الفرع
   - عد النقود الفعلية
   - مقارنة مع الرصيد المسجل
   - تحديد أي فروقات

3. **عملية التحويل:**
   - إنشاء عملية تحويل نقدية
   - تحديد المبلغ المراد تحويله
   - تحديد طريقة التحويل:
     * نقل يدوي للنقود
     * تحويل بنكي

4. **التسجيل:**
   - تسجيل المبلغ والتاريخ والوقت تلقائياً
   - تسجيل اسم المشرف والموظف المستقبل
   - إنشاء إيصال التحويل

5. **التحديث:**
   - خصم من خزينة الفرع
   - إضافة للخزنة الرئيسية
   - تصفير عهدة الفرع (تصبح صفر)

6. **التسجيل في اليوميات:**
   - إضافة العملية لليوميات الإدارية
   - تسهيل المراجعة والتدقيق

#### أنواع التحويلات

- **تحويل يومي:** في نهاية كل يوم عمل
- **تحويل للوردية:** في نهاية كل وردية
- **تحويل طارئ:** عند الحاجة لنقل مبالغ كبيرة

### دورة 5: الجرد والمطابقة

```
تحديد موعد الجرد
   ↓
إصدار قائمة الجرد المجمع
   ↓
توزيع قوائم الجرد على الفروع
   ↓
عد الكميات الفعلية (حسب اللون والحجم والموديل)
   ↓
إدخال الكميات الفعلية في النظام
   ↓
حساب الفروقات تلقائياً
   ↓
تحديد العجز أو الزيادة
   ↓
إنشاء سند التسوية
   ↓
توثيق الملاحظات
   ↓
طباعة التقرير
   ↓
النهاية
```

#### الخطوات التفصيلية

1. **التحضير:**
   - تحديد تاريخ الجرد
   - إغلاق المبيعات قبل الجرد
   - تحضير القوائم

2. **طباعة قائمة الجرد المجمع:**
   - الأدمن يطبع قوائم الجرد
   - كل فرع تحصل على قائمة خاصة بها
   - القائمة تشمل:
     * كود الصنف
     * الاسم
     * المواصفات (اللون، الحجم، الموديل)
     * الرصيد المسجل
     * حقل للرصيد الفعلي

3. **إجراء الجرد:**
   - فريق الفرع يعد الكميات الفعلية
   - تسجيل الأرقام على القائمة
   - التوقيع على القائمة

4. **إدخال البيانات:**
   - إدخال الكميات الفعلية
   - التأكد من الدقة
   - إرسال القوائم للمقر

5. **معالجة البيانات:**
   - النظام يحسب الفروقات تلقائياً
   - إظهار:
     * العجز (كمية مسجلة > كمية فعلية)
     * الزيادة (كمية فعلية > كمية مسجلة)

6. **سند التسوية:**
   - إنشاء سند يوضح الفروقات
   - تحديد السبب المحتمل:
     * كسر/تلف المنتجات
     * عمليات بيع لم تسجل
     * اختلاس محتمل

7. **الإجراءات النهائية:**
   - توثيق الملاحظات
   - تصحيح الأرصدة
   - طباعة التقرير النهائي

#### أنواع الجرد

- **الجرد الدوري:** كل ربع سنة أو كل ستة أشهر
- **الجرد الشامل:** سنوي (عادة في نهاية السنة المالية)
- **جرد عينة:** للمنتجات ذات القيمة العالية

## بنية قاعدة البيانات

### الجداول الرئيسية

#### 1. جدول المستخدمين (Users)

```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    full_name VARCHAR(255) NOT NULL,
    role ENUM('admin', 'supervisor', 'salesperson') NOT NULL,
    branch_id INT, -- NULL للأدمن، معرف الفرع للمشرفين والبائعين
    email VARCHAR(100),
    phone VARCHAR(20),
    national_id VARCHAR(20) UNIQUE,
    salary DECIMAL(10,2), -- للبائعين والموظفين
    status ENUM('active', 'inactive') DEFAULT 'active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (branch_id) REFERENCES branches(id)
);
```

```sql
CREATE TABLE branches (

    supervisor_id INT,
    status ENUM('active', 'inactive') DEFAULT 'active',

);
```

```sql

    phone VARCHAR(20),

    address TEXT,
```

## الاعتبارات الأمنية

### 1. التحكم بالوصول (Access Control)

#### المستويات
- **مستوى النظام:** ربط الصلاحيات بقاعدة البيانات
- **مستوى الفرع:** كل مستخدم يرى فقط بيانات فرعه
- **مستوى العملية:** صلاحيات محددة لكل عملية

#### آليات الحماية
- كلمات مرور قوية (8+ أحرف، أحرف كبيرة، أرقام، رموز)
- تغيير كلمات المرور دورياً (كل 90 يوم)
- حد أقصى لمحاولات تسجيل الدخول الفاشلة

### 2. تشفير البيانات

#### البيانات في الحركة (In Transit)
- HTTPS مع شهادات SSL معتمدة
- TLS 1.2 على الأقل

#### البيانات في الراحة (At Rest)
- تشفير كلمات المرور بـ bcrypt أو Argon2
- تشفير البيانات الحساسة (أرقام بطاقات، أرقام قومية)

### 3. تدقيق العمليات (Audit Trail)

#### المسجل
- معرف المستخدم
- نوع العملية
- البيانات المعدلة
- التاريخ والوقت
- عنوان IP

#### الاحتفاظ
- الاحتفاظ بسجلات التدقيق لمدة سنة على الأقل

### 4. النسخ الاحتياطية والاسترجاع

#### خطة النسخ الاحتياطية
- نسخة احتياطية يومية كاملة
- نسخ احتياطية تزايدية كل ساعة
- تخزين في موقع مختلف عن الخادم الرئيسي

#### اختبار الاسترجاع
- اختبار الاسترجاع شهرياً
- توثيق إجراءات الاسترجاع

### 5. الحماية من الهجمات

#### الثغرات الشائعة
- SQL Injection: استخدام Prepared Statements
- XSS (Cross-Site Scripting): تنقية المدخلات
- CSRF (Cross-Site Request Forgery): استخدام tokens
- Brute Force: حد أقصى لمحاولات الدخول

#### الحماية من DDoS
- استخدام CDN
- تحديد سقف للطلبات
- مراقبة حركة الشبكة
